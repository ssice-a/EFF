## Action 是通道来源

统一动画列表与导出读取所绑定 Action 插槽的实际曲线，涵盖形态键、骨骼、作者 Empty 和材质。删除曲线后立即从列表与导出消失；给现有绑定对象增加受支持曲线时自动参与导出。旧通道集合仅用于兼容已有工程及保存播放设置，不再作为导出白名单。材质部分分量有曲线时，其余分量使用当前静态值。动作的导出勾选、帧范围、循环、自动播放、速度、采样率和快捷键仍在动作级设置。

通道列表取消独立启用与删除按钮，曲线由 Blender Action/Graph Editor 管理。“添加所选对象”仍可为动作加入其他来源对象；现有绑定对象内新增曲线不需要再次点击。

同时修复真实导出发现的衔接问题：INI 移除内部哈希生成可读区段名后，原生几何写入器以已发布 Mesh 的文件路径解析其 Part、Mesh 和 Material 名称，不再用旧区段名查找。
