# 动画按导出 Mesh 收集通道

2026-11-16，本机 Blender 插件 0.50.35。

## 复现与原因

当前工程导出时报错：播放组“星环主图 UV 旋转”必须一起导出全部动画材质，缺少 `EFF_ring_mat_15`、`EFF_ring_mat_16.001`、`EFF_ring_mat_17.001`。这些材质仍绑定同一 Action，却已不被此次选择的 Mesh 使用。现场栈保存在 `diagnostics/animation-export-scope-20261116/before.txt`。

原有 `validate_export_members` 强制检查整个工程的 Action 成员，覆盖了原生导出器已经按资源收集通道的行为。此外，自动注册材质轨道时通过 `action_channels` 寻找播放组，会读取不参与本次导出的材质曲线，无关材质的失效 Action 插槽也会阻止导出。

## 修改

- 删除整个播放组必须同时导出的校验及 Mesh、特效导出的调用点。
- 自动注册材质轨道改用 `source_actions` 确定归属，不求值无关材质曲线。
- 沿用现有资源选择：导出 Mesh 的形态通道、实际使用的材质槽（含启用的材质切换选项）、绑定骨架，以及显式选择特效所依赖的挂点。共享 Action 不会额外引入其他资源。
- 保留共享动画 ID、时间范围、播放倍率、循环、自动播放、按键和导出勾选。参与导出的资源仍执行原有有效性校验。

## 验证与部署

`test_eiem_animation_export_scope_blender.py` 使用真实工程的 Mesh 与 EFF 材质副本，构造共享 Action：保留未使用材质、删除另一个材质、删除一个未使用材质的 Action 插槽，并让实际使用材质的轨道等待自动注册。修复前在无关插槽检查处失败；修复后完整原生导出成功，INI 仅包含当前 Mesh 对应材质的四个旋转矩阵通道，样本、共享 ID 与 0.5 播放倍率正确。关闭 Action 导出后再次导出，INI 不含动画或材质轨道。

形态动画、材质动画、混合 Action 通道、统一动画 UI 的真实 Blender 回归通过。原生导出、插件更新包、形态动画资源的单元回归共 81 项，80 项通过，1 项跳过。

额外运行挂点往返回归时发现既有问题：同场景恢复副本后路径由 `Orbit` 变为 `Orbit.001`，采样一致，但路径比较失败。注入部署备份中的旧成员校验并恢复其调用后仍然同样失败；本次没有修改挂点恢复和路径生成。这项失败独立记录，不作为本次材质动画修复已覆盖的功能。

0.50.35 使用现有事务安装器部署到 Blender 5.2 插件目录并核对包摘要，完整备份与安装回执见 `diagnostics/animation-export-scope-20261116/deployment.json`。现场 Blender 随后已退出，MCP 断开；用户明确暂不需要重新导出，因此没有覆盖当前游戏 Mod，也没有保存或改动用户工程来绕过校验。下一次启动会加载新版本；当前工程再次导出与实机验收尚未执行。
