# 离线构建与 F10 提交

2026-10-05 更新：以下记录描述现有整体候选重建方案。v35b 实机重建失败并出现 T pose；v35c 已部署但未验收。用户允许研究其他热重载方式，当前核查和按资源更新的研究方向见 [热重载替代手段](f10-reload-alternatives.md)。下面“已完成”中的原生重建/回滚描述是实现状态，不代表完整实机验收通过。

当前实施为 v34：首次替换随游戏资源加载，F10 直接重新加载当前 Mod。纯格式处理由 DLL 之外的共享打包器执行；Mesh、材质、贴图、INI、按键、显隐和形态绑定都进入同一候选代际。

## 已完成

- 版本化二进制清单、不可变原生输入、原子发布、作者关联外部监视器；Blender 调用同一 V34 EXE。
- 首次加载选择最新完整作者/控制/原命名输入表；不沿用冻结旧图，也不在登录期额外请求游戏资源。
- F10 创建当前作者请求；必要时调用外部编译器，然后分批加载隔离 Bundle/PFB。移除世界模型稳定等待门槛及新 Mesh 标识无法命中旧 Renderer 的卡住条件。
- 世界与已记录 UI 部件通过游戏原生释放、池失效、同步加载生命周期重新装配。所有当前 owner 先释放，所有匹配路径的普通闲置池清理，再装配新实例。保留 UI 配置并刷新世界跟随效果。
- 每 Mesh 的索引、骨骼、bindposes、形态与原版/作者贴图选择保持；提交时合并玩家数值并更新绑定缓存。过期候选拒绝，失败回滚旧路由与当前模型。
- 旧 Bundle 容器走 Unload(false)；共享来源 lease 每路径一份，残影消费者走 native Release。移除 3 代限制，不手工销毁仍被引用的原生资源。
- 独立 PNG EXE 手动转换；F10 不解码 PNG。备份和中间文件位于作者目录之外。
- 持久几何阶段缓存；像素、材质字段和控制编辑复用 Mesh/Renderer/骨骼构建。

## 本地证据

真实 LZY 的冷/缓存构建 136 个输出逐字节相同。像素编辑改变 1 个输入，材质字段编辑改变 1 个输入，控制编辑仅改变清单，Mesh 索引编辑使几何缓存失效并改变 2 个输入。损坏作者保留上一 current。

独立回读已编译原生对象验证 43 个 Mesh 的索引/bindposes/骨骼名表/形态、5 个材质的作者字段/贴图选择和 11 个纹理的全部像素/mip 字节。生产函数验证最新 60 条实际替换记录、物理范围/源与输出 hash、68 输入、18 文件加载闭包与编译控制一致性。

事务 mock 覆盖启动无额外原生请求、显式早期 F10、Mesh 标识改变、乱序 Bundle 完成、世界/UI 完整 Frame 提交、连续 8 次 F10、回滚、请求排空、旧容器 Unload(false)、共享 lease 复用及闲置池路径失效。这些结果不代替实机验收。

## 性能与边界

真实 LZY 冷编译当前约 22.4 秒；命中几何缓存的完整编译约 12.4 秒（此前约 21.1 秒）。发布阶段按输入使用 8 线程受控并行，仍在临时代际目录完成命名、编码、解码校验和写盘，`ready.tsv/current.tsv` 继续最后原子发布。已准备候选的生产后台 F10 请求平均约 0.296 ms；完整新候选首次验证约 1.19 秒。游戏原生加载和重装实例的端到端耗时尚未测得，不能承诺毫秒提交。

当前支持单 Mod、已提供的 LZY 世界/UI 基线及精确跟踪的世界/展示部件。persistent pool 和缺少已知部件生命周期的活消费者仍拒绝迁移，其他角色的基线发现另行实现。曝光失败资源隔离保留；没有穷尽原生 job fence 的结论。

## 用户测试

重启游戏一次以加载 v34b。进场后编辑实际 Mod 的资源：Blender 重新导出 Mesh/材质，或用独立 EXE 将修改后的 PNG 转为同名 `.tex` 并自动更新相关 INI 路径；INI 可以直接修改。PNG/PSD/转换器 EXE 可放在 Mod 内，无需声明，其他原生资源仍需正确引用。按一次 F10，观察修改是否生效，再检查按键、形态、走动与平 A 身体残影。未编辑时 F10 重装相同资源，外观应保持。旧青绿色测试贴图已经恢复。

本地构建和部署已完成；实机 COMMIT、画面和延迟仍待用户验收。证据在 `diagnostics/resource-directory-entry-20261005/v34-direct-full-reload`。格式和清理语义见 [离线包契约](offline-resource-package-format.md)。
