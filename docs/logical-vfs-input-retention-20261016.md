# 逻辑 VFS 路由与只读输入裁剪

2026-10-16，本机代码、配套软件及六个已安装 Mod 的生成文件已更新。安装文件与 SHA256 记录在 `bin/logical-vfs-20261016/installation.json`，原文件保存在同目录 `installed-backup/`。

## 当前行为

DLL 从 Mod 已有的 `source-inputs.bin` 取得明确的逻辑 Bundle 路径，并用共用 C++ VFS reader 一次解析当前两层目录。旧 CHK 文件名、路径及偏移只作为旧版本位置证据。读取当前范围后验证编译所需的 SHA256；物理位置改变而内容相同时可以直接使用原 Mod。源内容改变、逻辑项删除或载荷尚未下载时拒绝把旧字节规则套到新输入，内容变化仍由游戏外修复工具重建。没有加入游戏内资源发现或后台编译。

编译保留实际修改的输入、Prefab 根以及能引用这些输入的消费者，包括未直接修改但需要重定位依赖的中间节点。其余只读末端依赖继续使用游戏原资源。新增加的原生 Bundle 依赖边单独保留，不能因为裁剪对应视图而丢失 Shader、贴图或预加载引用。再次导出与新增 PFB 的共享描述也保存这些原生路由。

AnimeStudio 与 EFF Repair 共用按内容重绑索引的实现：对照所有逻辑 Bundle 的 MD5 和长度，校验既有索引记录范围的 SHA256，再暂存重写本机位置身份。相同内容的 CHK／范围移动不需要重新解析游戏 Bundle 或重新下载公共索引。不同内容不能给旧记录盖上新指纹；AnimeStudio 使用已有增量构建，修复工具要求匹配当前内容的完整索引。修复收据不再以本机索引文件时间作为游戏内容身份。
