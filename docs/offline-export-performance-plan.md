# 离线导出提速

2026-10-17 新增[Blender 全部资源重复导出优化与实测](blender-export-performance-20261017.md)：快照失效粒度、材质字段与磁盘图片解码复用，以及离线字节搜索。真实单顶点导出逐文件相同；几何变更的逐输入增量编译仍未实现。

2026-10-13。独立目标：在相同作者输入与消费者覆盖下减少完整冷导出耗时。保持编译输入视图后端与当前 compiled.bin 格式；不以缓存命中代替冷编译优化。不把游戏新增消费者发现计入本项完成状态。

## 已实现

- `ObjectFields` 只投影读取需要的字段，其他字段仍按 schema 与字节范围跳过。完整修改对象仍走解码/编码核验；投影结果禁止当作完整对象写回。
- 消费者匹配只读精确 Mesh/owner 引用；静态组件配对仍按 GameObject 的实际组件列表核验。
- PFB 根归属在单个 SerializedFile 内共享 Transform owner/parent/children 索引。每个根保持独立的遍历与 Renderer 集合；循环、重复子节点、父子不一致仍拒绝。
- 完整装配描述在同一成员内共享不可变 GraphData，根地址和组件序号分别构建。
- Renderer 骨架查询使用只读投影；实际修改或克隆节点才完整解码。
- 元数据阶段的原始/修改后 GraphData 直接生成 pristine 描述，后续证明与命名阶段复用同一成员 layout；巨大的 GraphData 在每个输入完成元数据后释放。
- 每来源证明独立编码/压缩，最多 4 个 worker 并行，按来源顺序拼接。完整产物格式与字节顺序不变。
- 装配字典以自身紧凑编码去重，省掉重复写出完整骨骼路径再算摘要的中间工作。去重按完整编码值判断，保留字符串、骨骼 palette 和装配的首次使用顺序。

没有本轮移除完整包 Encode/Decode 验证，也没有宣称已优化峰值内存。现有 8 个输入 worker 上限保留；后续根据实际内存数据调整工作调度，不减少覆盖。

## Physics 参数增量编译（2026-10-24）

Physics-only 导出此前逐个重建所有命中 Prefab。Chen 的一个 Physics 组实际命中 109 个输入；串行增量墙钟约 13.24 秒，比约 10.76 秒的全量冷编译还慢。加入每输入目标过滤后，Chen 的目标网格对为 427 组，但耗时没有明显变化，说明主要成本是独立 Prefab 构建而非扫描无关目标。

现在 Physics 参数增量以 4 个有界 worker 并行处理命中输入，各 worker 独立生成视图、隔离摘要和证明，再按输入顺序合并共享成员证明。普通 Physics 构建器默认仍处理完整目标集合。差分测试逐个验证 122 个输入的启动摘要、实际字节回放、隔离输入摘要与增量产物编解码；骨骼位置/拓扑变化、Physics 与其他资源混改、未变化资源均拒绝走此增量路径。

同一 Chen 副本最新一轮实测：Physics 增量编译阶段 4.57 秒，全量冷编译 11.28 秒；相对串行增量减少约 65.5%。增量的 4.57 秒仍不是毫秒级端到端结果。全量与增量的逐输入启动视图一致；两包内部 namespace key 按作者摘要变化，故不要求整包逐字节相同。编解码稳定性和普通/隔离输入自洽均有独立断言。最新回归产物增量为 58,474,162 字节、冷编译为 58,473,607 字节，相差 555 字节。

阶段计时中，Physics 构建 worker 累计约 5.50 秒，Patch 成员约 2.03 秒，生成成员配方约 1.29 秒，隔离命名约 1.01 秒；这些是并行 worker 时间总和，不能相加解释墙钟。其余可见成本包括证明 hydration 约 0.68 秒、整体 compiled.bin 编码约 1.18 秒、运行时索引校验约 0.42 秒。对稳定样本达到亚秒需要进一步复用参数无关的 Prefab 构建/证明，并避免重新压缩整个索引；这需要单独验证缓存失效粒度。

已安装的 Chen `compiled.bin` 为 58,473,531 字节：压缩运行索引 23,627,495 字节、122 个独立证明块共 34,844,915 字节。gly 为 71,273,604 字节：索引 30,323,088 字节、166 个证明块共 40,949,043 字节。体积主要来自现有单文件运行索引和每 Prefab 证明，不是 Physics 作者资源本身；Physics 参数变更的增量输出与冷编译相差不足 1 KB。

上述是先前 Physics 专用增量阶段的历史测量；当时没有改变包格式。该路径已由下述五类统一资源更新替代，不能把历史秒数作为当前快路成本。
