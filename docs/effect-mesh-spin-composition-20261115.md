## 用户操作

1. 选择 `基础粒子_柔光` 根，在 **发射器** 快捷列表点击 `网格自旋_fx_nr007 · Mesh 网格`。列表直接显示当前对象名称及渲染方式，包含 `Internal` 等原生辅助节点下的发射器；只列仍存在的对象，不依赖层级折叠状态。也可在大纲直接选择该发射器空物体。
2. 在数据属性 **EFF 特效 · 原生结构 → ParticleSystemRenderer** 顶部的 **调用 Mesh（场景物体）** 选择网格。名称框可下拉搜索；名称框右侧独立吸管图标可从视图或大纲吸取 Mesh，不必先清除当前绑定。选择后更新当前 Mesh，取消保留当前 Mesh。留空沿用原生 Mesh 引用；游戏逻辑资源引用保留在 **原生 Mesh 引用 / 游戏逻辑资源** 折叠栏。
3. **编辑粒子 Mesh** 会选中资源网格，Tab 进入编辑模式可改顶点和 UV。自定义 Mesh 选取时采用物体原点的位置和朝向，之后发射器可独立摆放；修改源物体摆放后，可点 **采用 Mesh 当前变换** 重新对齐。旋转轴心始终是物体原点，不在导出时隐式居中。若希望围绕几何中心旋转，先显式使用“物体 → 设置原点 → 原点到几何中心”，再采用变换。
4. 在当前根或发射器面板点 **添加发射器**，模板选择 `网格自旋_fx_nr007`，填写新名字。插件创建独立原生 ParticleSystem/Renderer；不要直接 Shift+D 复制发射器 Empty。
5. 新发射器初始共用 Mesh 和材质。要独立改 Mesh：选资源网格 Shift+D 复制，确认网格数据为单用户，再回到新发射器将 **调用 Mesh（场景物体）** 指定为副本，然后编辑该副本。材质仍共用；修改共用材质会影响所有引用者。
6. 新 Mesh 可以使用场景中通过任一现有入口导入的 EFF 材质，包括普通武器、人物或其他特效的材质；不要求属于当前特效根。面材质槽和无 UV 网格都保留。普通 Blender 节点图尚无游戏 Shader 编译器，不能把预览节点图等同于已导入的游戏 Shader。
7. 选单个发射器导出仅包含它；选根导出四个发射器。本轮只生成诊断原生包，没有覆盖游戏 `mods/lizi`。

## 本轮代码修正

- 复制快照保留工作区扩展的 FileID→CAB 表，避免逻辑材质被作者材质替代后不可达。
- JSON 值跨来源传递使用字段名、类型和层级匹配；忽略与值传递无关的二进制编辑器标记，目标 TypeTree 仍负责重新编码，真实字段变化继续拒绝。
- 复制已有作者 Mesh/Texture 时匹配不可改的原生标志；不再随意选同类模板，避免 `m_IsAlphaChannelOptional` 的原生校验失败。
- 从新图片构建作者贴图时，使用本地作者模板的导入/流式标志并保留所需色彩空间，避免把游戏贴图的保护字段混入作者模板。
- 模板匹配集中在 `eiem_effect_resources.py`，导出和剪贴板共用。未增加全局游戏索引查询。

仍有边界：目标来源完全没有 Mesh 模板时，通用跨根粘贴尚不能自动引入新的原生类型。此次组合来源已具备 Mesh 模板，同根新增 Mesh 发射器可直接使用。
