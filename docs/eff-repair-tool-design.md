# EFF 修复工具设计

2026-10-15。根据用户最新要求，将原管理器方案收敛为独立的游戏外 Mod 修复工具。本文记录产品范围；图形界面、公共索引导入、下载与修复后端已实现，本地验证范围见[实现记录](update-workflows-20261015.md)，在线索引尚未发布。解包资源更新由 AnimeStudio 负责，Blender 负责接受更新后的来源，不纳入本工具。

## 产品范围

1. 检查工具与完整索引更新，在软件内下载与本机实际游戏资源匹配的完整索引。
2. 自动识别游戏及 `plugin/mods`，保留手动选择游戏、Mod 根目录或单个 Mod 的入口。
3. 在游戏外修复已有 Mod，完整校验后替换生成结果；不要求玩家安装 Blender 或重新解包。

第一版不包含 EFF 安装/卸载、Mod 商店、启停管理、预览卡片库或常驻托盘服务。拖入 Mod 文件夹可以作为修复输入，不能因此扩展为完整管理器。

DLL 不查公共索引、不发现新增 PFB、不启动兼容编译器、不自动回写 Mod。地图切换、首次加载和 F10 均不承担版本适配。游戏只使用已经在游戏外修复并提交的 Mod；现有运行时资源读取、集合组合和作者控制仍有正常加载成本。相关自动适配实验不再作为实施方向。

## 更新与目录

维护端为每个受支持的实际游戏资源版本发布完整公共索引及内容证明。不同作者、玩家、修复工具与 AnimeStudio 共用同一资产/依赖目录，不为每个 Mod 发布一套大索引。用户没有旧索引时也能全量下载使用；不要求玩家保留旧版本分块或维护增量目录。

更新检查区分：匹配的完整索引可下载、游戏已更新但索引尚未发布、索引已就绪但 Mod 尚未修复、网络检查失败。不能无条件套用远端最新索引，不能将下载完成显示为修复完成。工具可以提示配套运行组件不兼容，但本次范围不包含自动替换游戏 DLL。

公共内容身份不得依赖维护者的盘符、绝对目录或文件时间。本机 eidx/AnimeStudio 保留资源指纹与工作区校验；公共包已携带逐 Bundle 内容证明，导入核验后建立本机绑定，不直接分发维护者工作区状态或跳过内容验证。公共索引同时供 AnimeStudio 浏览、定位与提取本机资源使用。

默认先验证保存路径，再读取已运行游戏位置、可确认的启动器记录及常见目录。唯一有效安装可以自动填入；多个安装供用户明确选择。不默认全盘递归扫描。手动选择接受游戏 EXE、游戏根、games 父目录和单独 Mod 目录；实际检查游戏数据是否就绪，不将预下载临时资源当成当前资源。已有基线有效的 Mod 直接可用，不因更换 Mod 强制下载或修复。

## 玩家：修复已有 Mod

检查包内作者声明和资源，使用当前完整索引重新定位声明的 Mesh、Material、Texture 与其他来源，沿当前依赖图筛选并精确确认全部 Renderer/PFB 消费者。更新中新增的命中 PFB 包含在本轮结果中，不依赖玩家在游戏中逐一遇到。

复用作者包中的网格、贴图、材质参数、形态动画、控制与声明，读取当前游戏中相关来源并重新生成编译输入。保留无关文件与仍适用的玩家设置。缺少必需作者资源、资产无法唯一定位或结构不兼容时，报告具体对象并保留原包，不用同名资产猜测替代。

暂存、核验并备份后提交生成结果；索引下载、Mod 编译与最终提交分别记录状态。游戏运行时可检查和准备下载，第一版在游戏退出后提交活动 Mod 的修复，避免与已打开的运行资源并发更新。

## 与 AnimeStudio、Blender 的职责边界

本工具只修已有 Mod，不选择作者解包工作区、不改写 `source/manifest.json` 或源快照，不修复或重存 `.blend` 工程。

作者在 AnimeStudio 对新游戏资源重新解包时，由 AnimeStudio 依据原解包记录更新已有输出及来源数据，保持原目录可被工程继续使用。Blender 在下一次导出前识别来源更新，刷新当前来源绑定、模板和相关缓存，保留工程内的作者修改。完整契约与待验收边界见[解包资源更新](exporter-source-baseline.md#2026-10-15重新解包更新已有资源与-blender-接入)。

公共索引的内容核验与本地读取能力可以共用，但两条操作独立：玩家只用本工具修 Mod；作者使用 AnimeStudio 重新解包，再从原 Blender 工程导出，无需经过本工具修复源包。

## 当前证据与发布边界

- 已在隔离目录用新游戏索引重编译五个旧 Mod，作者文件保持相同；已安装版本的新会话确认五个 Mod 被读取。画面及本次 F10 提交仍需独立验收，详见[本次游戏更新修复](game-update-compatibility-20261015.md)。
- 当前完整 eidx 原始 830958103 字节，gzip 90184369 字节，已核验往返 SHA。传输压缩不等于已经缩减解压占用；维护端 `.eidx.bundles` 辅助记录不属于玩家修复的必需下载。
- 公共索引跨机器导入、更新检查和修复工具界面已实现，当前公开目录尚未发布；本地 Mod 修复与重复跳过已验证。AnimeStudio 的旧输出更新与 Blender 接入分别验收，不作为本工具的功能。详见[实现记录](update-workflows-20261015.md)。

## 实施与验收顺序

1. 先完成公共索引的内容核验、跨路径导入与三端共用解析，保留对旧本机索引的内容验证。
2. 将已验证的旧 Mod 修复流程封装成后端，核验作者文件和玩家设置保持、当前消费者完整、新增 PFB 纳入结果。
3. 接入更新检查、目录识别、下载校验、任务进度和结果界面。
4. 验证未变 Mod 跳过、跨机器同内容索引、缺失/歧义资产、来源移动、不兼容变化、多 Mod 共享来源、失败回退与重复修复；不要求玩家安装或操作作者工具。
