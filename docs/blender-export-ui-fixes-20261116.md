# Blender 0.50.30：选择导出、材质来源与面板

## 行为

- 选择武器／角色 Mesh 只导出所选网格及其必要材质、贴图、动画，不按挂载关系追加特效根。要导出特效需明确选择根或发射器；混选 Mesh 与发射器不扩大为整根。资源 Mesh 或预览几何不会反向选择父级特效。
- 改名的原生作者材质通过已保存的模板身份和原始 Shader 引用恢复基线，不以材质显示名称是否相等判断来源。已有精确来源或外部导入记录优先；外部材质不可误用结构模板的 Shader。差异仍相对正确基线保存。当前星环 11 个材质已就地迁移，无需重新打开工程。
- 面板按字段结构缓存分组、参数归属；每次重绘仍读取当前值与开关。RNA 控件集合改为单次扫描，避免逐个参数线性查找形成平方复杂度。不长期缓存 RNA 引用；字段增删、Shader 更换及撤销后会按新结构重建。
- 主图、混合图、Mask、扰动、法线的受支持旋转输入统一在各自路径下的“UV 变换与旋转”中显示“启用 UV 旋转动画”勾选框。首次启用创建现有四通道材质动画，关闭保留曲线、重新启用不覆盖修改。各层独立；固定角度、滚动速度仍是各自独立的输入。

## 验证

- 248 项 Python 回归完成，1 项跳过；真实 Blender RNA／只读面板／UV 动画启停测试通过。
- 新增选择契约测试覆盖生产 `selected_export_resources` 入口：单 Mesh、根、发射器、混选、资源 Mesh 和根优先级。
- 当前场景的 `MeshS_wpn_sword_0022_01_lod0_0.001` 实际冷导出约 **1.74 秒**，1 个 Mesh、0 个特效，未产生 effects 目录。
- 当前星环根真实导出成功，11 个独立材质均使用 `m_fx_interactive_shokcwavetower_804.mat` 的准确来源，保留修改。完整星环根冷导出约 **16.14 秒**（整理 11.18、编译 3.02、校验 0.06、发布 1.86 秒）；本次未把此导出耗时声明为已优化。
- 当前 724 个自定义键／720 个控件的材质，同一 Python 面板绘制测试，5 组、每组 30 次，中位数从 **25.55 ms 降至 2.60 ms**，约减少 90%。这是参数面板代码耗时，不是游戏帧率或完整 GPU／界面渲染时间。
- 测试产物和报告在 `diagnostics/blender-export-ui-20261116/`，Mesh 与星环分别输出到独立诊断 Mod，未覆盖用户游戏 Mod。
