## 快捷键

项目 `config/eff.ini` 与游戏 `plugin/eff.ini` 均设置为：

```ini
[Hotkeys]
reload=NUMPADMINUS
gui=INSERT
```

`NUMPADMINUS` 对应小键盘区域减号（VK_SUBTRACT，109）。本次修改时游戏已退出，下次启动直接使用该键。代码中保留的 F10 默认值与历史日志标签不影响显式 INI 绑定。新键的游戏内触发仍待下一轮确认。
