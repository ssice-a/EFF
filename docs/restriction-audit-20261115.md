# 2026-11-15 导出限制修正

范围：Blender 材质与粒子 Mesh 导出、原生 Mesh 写入、Skeleton/Transform/动画的 Python 与 DLL 校验。检查现有工作区，不重置未提交内容。特效统一资源装配另见 [资源架构审查](effect-resource-architecture-audit-20261115.md)，此次材质入口修正不代表该装配已统一。

## 已修正

- 粒子 Mesh 错误要求材质必须属于当前特效根。现在复用现有整包导入、Mesh 材质导入按钮创建的 Material 和 `eiem_*` 数据，不新增材质选择流程。原生结构、Shader/Texture 逻辑绑定在导入时保留于 Material；Format 3 稀疏材质的作者元数据随既有材质文件往返。旧场景可从已加载的特效文档恢复，不在导出时重新读取材质源包或游戏索引。
- 删除单材质槽限制，保留各面的材质索引、原生 SubMesh 及对应 Renderer 槽。删除必须有 UV 的限制，无 UV 时不伪造 UV 或切线；预览需要的默认 UV 不写入导出。
- 已导入原图不因被普通场景材质引用就转为作者贴图。导入时记录图片来源与内容，未改图片继续使用游戏逻辑引用；作者换图或绘制图片才编码本地 Texture。此处不能消除下述原生构建器仍保留旧成员的重复载荷问题。
- Material 保存属性表允许添加 Shader 参数，不再因参数未出现在来源材质的保存表就拒绝；字段按实际 TypeTree 生成，仍检查分量数及有限值。
- 普通 Transform 与动画样本接受负缩放、零缩放；Skeleton 绑定变换接受负缩放，零缩放仍因逆绑定矩阵不可逆而拒绝。Python 导出、作者工具和生产 DLL 的规则一致。
- 移除混合图 HDR 的 64 倍硬上限，保留非负有限值和便于拖动的软范围，亮度调整仍保留颜色和 Alpha。

## 保留的真实约束与能力缺口

原生整数位宽、有限数值、有效资源引用、归一化四元数、骨架逆矩阵和 Unity 曲线时间语义属于格式/数学约束。Unity Gradient 的关键点数量限制不能直接删除。曲线纵轴不限制在 0–1。

任意 Blender 节点图没有对应的游戏 Shader 编译器。已导入的任何 EFF 材质可以跨用途使用；未导入的任意节点图不能伪装成可运行的游戏 Shader。粒子 Mesh 当前输出静态评估形状；逐粒子蒙皮、任意组件类型跨来源创建、直接 Shift+D 后自动分配全套原生身份，以及未烘焙的复杂 NLA/约束仍属实现缺口。不能仅删校验后静默丢失数据。

剪贴板和预览预算属于编辑器实现预算，不代表游戏格式上限。本轮未把这些预算改成新的格式限制，也未宣称所有编辑能力已覆盖。
