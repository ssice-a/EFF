# 跨来源特效材质修改后的导出修复

## 复现与原因

当前武器工程中，`基础粒子_柔光` 根引用了跨来源粘贴的星芒发射器。其游戏材质 `M_fx_liino_kv_139` 的 `_TintColorIntensity` 从 31.2 调为 50 后，导出报错：

```text
特效：游戏资源引用的来源参数已改变，请创建作者资源后再编辑：M_fx_liino_kv_139
```

材质面板允许修改该材质，但导出仍把修改后的对象作为只读游戏引用交给文档校验，缺少转换为作者材质的步骤。这是导出器的问题，不要求作者降低亮度或手工制作资源副本。

## 修复后的资源归属

未修改的跨来源游戏材质继续引用游戏。修改参数或换用本地贴图后，导出器使用当前来源中实际结构相同的 Material 模板创建作者材质，保留修改值；未修改的 Shader、Texture 仍通过逻辑路径引用游戏，并声明提供这些资源的来源 Prefab 租约。不会为此复制来源特效或其游戏贴图载荷到运行资源中。

模板必须具有完全相同的原生结构；缺少兼容模板时明确报告原因，不猜测序列化结构。作者材质的逻辑引用允许作为资源自身的引用保存；导回后再次修改时重新生成其载荷，避免继续导出旧参数。

AnimeStudio 同时修复了外部引用表扩展后的对象偏移：必须在更新 SerializedFile 外部引用表后重新读取对象区间，否则新增引用导致数据偏移变化时，会用旧位置解码新文件并报 `Array count exceeds object extent`。
