# EFF 管理器设计（已被修复工具方案取代）

> 2026-10-15 用户将范围收敛为游戏外 Mod 修复工具：检查更新、自动/手动选择位置、修复 Mod。解包资源更新由 AnimeStudio 负责，Blender 接受其更新，不纳入修复工具。当前实施依据为 [EFF 修复工具设计](eff-repair-tool-design.md)。下文的安装/卸载、启停与完整 Mod 库等管理器功能属于被取代的历史方案，不再作为第一版需求。

2026-10-15，历史设计记录；管理器产品尚未实现。现有索引、编译器与运行 DLL 不等于已具备本页交互功能。

## 已确定的范围

- 独立游戏外管理器，包含 EFF 本体和 Mod 的安装、更新、启停、卸载及兼容状态。
- 旧 Mod 的游戏更新适配在游戏外完成。维护端全量生成并发布当前游戏的公共索引，玩家需要适配时下载全量索引；不依赖玩家持有旧索引或未变分块，不做玩家端增量索引维护。
- 已安装 Mod 共用一份对应当前游戏内容的索引。作者基于当前资源导出的 Mod，来源核验通过后可直接使用，不因安装新 Mod 强制下载索引或重新编译。
- 玩家使用管理器和 Mod 包，不需要 Blender、作者工程或手工解包。游戏内不发现未知 PFB、不补编译；保留正常读取、校验、组合、替换、控制与 F10。
- 当前 `.eidx` 原始大小 830958103 字节，gzip 为 90184369 字节。`.eidx.bundles` 是维护端增量构建记录，现有来源编译器消费完整索引时不需要分发它。当前格式仍需约 831 MB 解压占用，缩减格式需独立实测。
- 公共索引必须改成按实际内容可跨机器核验的发布形式。现有本机路径/时间组成的资源指纹不能直接成为所有用户的下载匹配依据。
- 修复所需的完整公共索引与配套修复组件由管理器内下载。索引维护者随每个受支持的游戏资源版本发布全量索引，不要求玩家去解包软件或发布页手工寻找、导入；不同 Mod 作者共用同一套游戏索引，不各自重复发布相同目录。
- 拖放是 Mod 安装的主要入口。玩家将完整 Mod 文件夹或支持的压缩包拖到管理器窗口即可进入安装，不再要求选择目标 Mod 目录或手动复制文件。
- 软件需要提示完整索引更新：维护端发布与本机游戏内容匹配的新索引或索引修订后，在导航及修复中心显示更新状态、发布版本、下载大小与入口。公共索引同时供 AnimeStudio 与 EFF 管理器使用，不维护两套内容不同的完整索引。

## 维护端发布与软件内修复

索引维护端为每个受支持的游戏资源版本生成、校验并发布完整索引和发布描述。描述至少包含展示版本、实际内容匹配证明、索引格式、压缩/解压大小、完整文件摘要和下载位置；配套编译组件的结构能力单独声明。不能仅凭游戏版本文字或本机目录时间选择索引，也不能无条件选择最新文件覆盖所有区服/资源组合。发布源接入尚未实现，不把本地测试文件当作已上线的公共下载。

管理器检查本机实际资源和已安装 Mod：当前基线且核验通过的 Mod 直接可用；需要适配的 Mod 汇总到修复中心。在软件内获取对应完整索引及可用的配套修复组件，显示下载大小和进度；核验、解压和各 Mod 的本地修复串成一个任务。玩家不选择 eidx、不执行命令、不打开 Blender。显示修复结果和具体失败原因，未通过内容匹配不对用户 Mod 提交编译结果。

下载的是公共目录与修复工具，Mod 作者的网格、材质、贴图、动画和规则继续来自已安装的 Mod 包。修复不等于下载另一作者的 Mod 或通用角色编译包；包内缺少必需作者数据时明确报告。

所有 Mod 共用当前资源对应的一份索引。用户没有旧索引时按全量下载设计，维护和验收不依赖旧版本分块；`.eidx.bundles` 不作为玩家修复所需下载。游戏出现工具不支持的接口/结构时显示需要更新公共组件，不能把索引更新描述成能够修复所有任意变化。

## 更新提示

启动管理器或用户点击检查更新时获取索引发布描述，后台检查不阻塞普通 Mod 列表。不能以“远端版本号更大”直接认定本机需要更换索引，先匹配实际游戏资源内容、区服/资源组合和索引结构能力。

- 本机资源对应的新版完整索引已经发布：显示可下载状态和受影响的 Mod，提供“下载并修复”入口；同资源的新索引修订单独说明，不伪装成游戏更新。
- 游戏资源已变化，对应完整索引尚未发布：显示“等待对应索引发布”，保留仍可验证的 Mod 状态，不把不匹配的旧索引作为新版本使用。
- 当前完整索引已就绪：显示索引状态和仍需修复的 Mod；基线有效的新 Mod 不因提示更新而被无条件重新编译。
- 网络检查失败：显示无法检查或重试，不声称已经是最新版本。下载/校验失败不替换已验证索引。

下载的是选中版本的完整文件，不依赖用户保存旧版本。新索引就绪不等于 Mod 已修复，下载完成、内容匹配与各 Mod 编译提交分别有明确状态。

## 与 AnimeStudio 共用索引

当前原始数据即 AnimeStudio 的 `EFF_END_FIELD_INDEX` 格式 3，包含资产名称、Container 路径、类型、PathID、所属 Bundle 与 CAB 依赖。gzip 是发布传输包装，不是第二套目录内容。未来若采用字典编码或分块压缩，AnimeStudio、管理器和来源编译器必须配套读取同一公共格式，不能只保留管理器能读的裁剪目录再宣称可用于完整解包。

现有 AnimeStudio 的工作区复用同时检查本机 VFS 指纹、manifest 和 `.eidx.bundles`；资源指纹包含相对文件位置和修改时间，不能直接将作者机器的工作区状态分发给另一台机器并保证被接受。因此还需公共索引导入与内容核验适配：先确认发布记录对应本机的实际 Bundle 内容，再建立本地资源位置绑定与工作区状态；可以扫描已下载索引生成本地辅助记录，不重新读取解析全部游戏 Bundle。不能简单跳过核验或把当前 MD5 盖到未经证明的旧资产记录上。

AnimeStudio 使用该完整索引浏览和定位资产，提取内容仍从用户本机的游戏 VFS 读取；下载索引不包含或替代游戏原始资源。现有版本尚未实现上述公共下载索引跨机器导入，不能保证直接手工复制另一台电脑的 eidx 后就会复用。

## 游戏目录识别

默认自动识别，始终提供手动选择。自动检测只读，检测到路径不等于授权安装或卸载。

优先级：保存的游戏路径、已运行游戏的可执行文件路径、可确认的启动器安装记录及其已配置的游戏目录、常见安装目录。启动器位置不等于游戏位置，后者必须独立验证。启动器记录读取器需要用实际配置核验，不能猜键名和路径后宣称已支持。

候选根至少核验 `Endfield.exe`、`GameAssembly.dll`、`Endfield_Data/StreamingAssets/VFS`。游戏数据尚未就绪时显示未完成状态，避免误认启动器、下载临时目录、预下载 ZIP 或用户解包副本。

只有一个有效安装时可自动填入并显示完整路径；多个安装列出候选供用户选择，不根据最近修改时间私自决定。保存绑定后，下次验证原路径是否仍有效。

手动入口接受 `Endfield.exe`、游戏根目录，或启动器的 games 父目录；用户选上级目录时检查直接子目录中的有效安装。额外搜索是用户选择目录后的显式操作，显示进度且可取消，不默认递归遍历所有磁盘，不沿目录链接无限搜索。

选定游戏目录后，管理器自动使用其 `plugin/mods`，无需再要求用户寻找 VFS 或 Mods 路径。保管停用 Mod 的目录须位于 DLL 扫描范围之外，并由管理器记录归属。

## 安装和更新

EFF 本体由受支持的完整配套包安装，记录实际写入文件、内容摘要与安装前备份。当前布局包括游戏根的代理 DLL 及 `plugin/eff.dll`，更新默认保留 `eff.ini`、Mod 和玩家状态。

安装前检查目标同名代理。已由本管理器安装且摘要相符的文件可以正常更新；未知同名代理不能直接覆盖，因为它可能被其他插件使用。界面展示冲突及可操作选项，未验证共存方式不自动合并加载器。

Mod 以窗口拖放安装为主要入口，保留文件选择作为辅助入口。接受完整文件夹与 ZIP；第一版不宣称支持所有压缩格式，7z/RAR 等需要接入相应读取器后再开放。拖入后识别实际 `mod.ini` 根，检查配套作者资源和 `compiled.bin`。单个有效新 Mod 使用已绑定的游戏路径直接暂存、校验并安装；不逐次询问目标目录。压缩包含多个 Mod 时显示识别列表；同一 Mod 已存在时显示更新对象并保留仍适用的玩家状态，不能只凭文件夹名将两个作者的 Mod 当作同一个。无法识别的文件说明原因，不移动或改写原作者包。

先暂存、校验，再发布文件。游戏运行时可以查看、检测和准备下载；涉及已加载 DLL、活动 Mod 或来源文件的安装、卸载与适配提交要求退出游戏。第一版不增加运行中安装/卸载的额外生命周期。

## 卸载

卸载 Mod 只处理选定 Mod 的受管理目录，其他 Mod 不受影响。玩家设置是否清除作为明确选项展示；卸载和停用是不同操作。

卸载 EFF 默认移除属于 EFF 的运行文件，保留 Mod 和配置以便重装。完整清理需要明确勾选具体数据。仅当目标仍是本管理器安装的文件时才删除或恢复其安装前备份；目标已被其他程序改写则报告冲突，不能强删或将旧备份覆盖回去。不得递归删除整个 `plugin` 目录。

安装、更新与卸载记录保存在管理器的状态目录中，不能随卸载运行文件一同提前删除。已有手工安装先识别并列出归属，无法确定的文件保留，不将所有同名文件默认为 EFF 所有。

## 第一版主要入口

参考 SSMT 类管理器的导航与卡片组织。已查阅 [SSMT4](https://github.com/Perxenic-Acid/SSMT4) 的 App、ModCard、管理页布局和主题源码，参考快照为 `0716cc3e4adb761a0b81e2da258a5e40e58f25a6`；这是源码结构参考，尚未制作 EFF 管理器画面。参考页面组织与操作方式，EFF 的安装、来源核验和编译仍使用自身后端。

- 左侧导航：概览、我的 Mod、修复中心、下载任务、设置。
- 概览：当前游戏、安装目录、EFF 安装状态与安装/更新/卸载入口；目录自动识别和浏览入口在此。
- 我的 Mod：预览卡片/列表、名称、作者（有元数据时）、启用开关、兼容状态；工具栏提供搜索、筛选、导入与批量操作。点击条目查看详情、更新和卸载。缺少预览图或作者字段时使用明确占位，不阻止安装。
- 拖放：窗口可见区域接收有效 Mod，拖入时显示安装覆盖层；普通单 Mod 不要求先进入某个子页或打开导入对话框。
- 修复中心：显示游戏资源对应的索引状态、待修复 Mod 和一键修复入口。索引下载/核验、资源准备、编译、提交与结果在同一任务内展示，不让玩家分别调用工具。
- 下载任务：汇总完整索引、EFF 组件与修复工具下载，显示进度、大小与重试入口；未配置或尚未发布的下载源不能显示虚假可用状态。
- 设置：游戏路径、下载位置、备份和日志。技术字段保留在诊断详情里，普通安装和修复流程只展示用户需要判断的状态与操作。

## 验收重点

- 未找到、单安装、多安装、路径移动、启动器与游戏不同盘、手动选择 exe/根/games 父目录。
- EFF 首次安装、更新保留配置、未知同名代理、手工旧安装接管、游戏运行时延后提交。
- Mod 文件夹/ZIP/多 Mod 导入、重复身份更新、状态保留、启停与独立卸载。
- 卸载保留其他插件及游戏原文件，安装文件被外部修改时拒绝误删，安装失败可恢复。
- 用户没有任何旧索引时全量获取，多个作者共用目录；当前基线 Mod 不强制修复；未知游戏内容不强行套用其他索引。
- 软件内匹配版本、下载和核验完整索引、完整修复任务、未发布资源/下载失败/资源不匹配的准确状态。
- 新完整索引发布提示、本机已更新但索引未发布、同资源索引修订、网络失败不假报最新、下载完成与修复完成状态分离。
- 同份发布索引由 AnimeStudio 与管理器接受；跨安装路径、不同文件时间但实际内容相同可核验导入，内容不同和来源缺失拒绝；不重新全量解析游戏 Bundle。
- 全窗口拖入文件夹/ZIP、嵌套目录识别、单 Mod 直接安装、多 Mod 列表和重复身份更新；不修改拖入的原文件。
