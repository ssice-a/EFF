# 柔光粒子的预览与运行参数核对

## 已确认的差异

用户观察到 Blender 为散点，游戏中为波浪状连续粒子。不能仅凭非零计数、READY/PLAY 日志断言视觉正确。

`plugin/mods/lizi` 原柔光发射器采用世界空间模拟，游戏日志 `simulationSpace=1` 与编译后 `moveWithTransform=1` 一致。它从半径约 3.4 × 2.0 厘米的圆周边缘出生，全部寿命为 1.8 秒，初速度为零，局部速度固定为 Y=-0.414227；每秒 16 个，保留来源的多段尺寸变化曲线。该配置形成狭窄的同向流，挂载的武器运动又会保留不同出生时刻的世界位置。当前 Blender 场景没有游戏中的武器待机/角色动作，因而不能直接作同运动条件下的对照。

固定速度和发射率对应沿行进方向约 0.414227/16=0.0259 米的间距，小于当前 0.04～0.08 米的初始尺寸；重叠与材质高亮会使散点更容易看成连续带。该数值解释了风险，不代替实际画面中具体形状的验证。

已逐对象解码实际编译的 SerializedFile：柔光的参数与 Blender 编辑文档一致，Noise、Trail、轨道速度、径向速度均未启用，也没有挂在它身上的 Animator/AnimationClip。来源 `lizi_01` 节点已被禁用并从主层级断开；其发射和 Renderer 同样关闭。柔光附带的 `VFXAutoEmissiveRate` 原本已经禁用，不能将它当作本次波浪轨迹的确定根因。

上述证据支持检查出生分布和运动条件，但**尚未完成新配置的游戏视觉确认**，不能排除仍有其他画面差异。用户明确要求世界空间，粒子出生后应留在世界；不能通过改为局部跟随武器来消除合法的世界轨迹。初次测试曾改为局部，已按用户要求恢复世界空间，编译后对照确认此次恢复仅改变该字段。

## 从空白重建当前柔光

使用本机 AnimeStudio `--create-eff-effect` 从 TypeTree 默认值生成空白 ParticleSystem，再赋予明确的作者参数；不继承原游戏发射器的模块状态、尺寸曲线、子发射器或 Sprite 数组。沿用原柔光材质和 Renderer，保留用户当前蓝/粉颜色端点，避免同时改变运动和材质。

| 项目 | 重建后的参数 |
| --- | --- |
| 模拟空间 | 世界，出生后不跟随武器挂点；出生方向按当时发射器姿态确定 |
| 渲染 | Billboard，沿用原柔光材质与顶点流 |
| 出生范围 | Box 体积，局部位置 (0,-0.35,0)，尺寸 (0.12,0.70,0.08) |
| 发射 | 16/秒，4 秒循环，无 Burst，容量 64 |
| 寿命 | 每个粒子随机 1.2～2.2 秒 |
| 初始尺寸 | 随机 0.04～0.08 |
| 速度 | X/Z 各随机 -0.025～0.025，Y 随机 -0.12～-0.04 |
| 减速 | 生命周期速度系数从 1 线性减到 0.15 |
| 颜色 | 保留用户端点，增加出生淡入和死亡淡出 |
| 脚本 | 从柔光新增对象中移除 VFXAutoEmissiveRate 组件 |

只有柔光 ParticleSystem、它的 GameObject 组件列表以及被移除的组件发生原生数据变化。其他发射器、材质、挂点和 LOD 装配保持一致。重建仍使用原特效工作区作为装配容器与资源来源，容器名称不是其粒子行为的来源证明。

测试包已通过正式 Blender 导出器覆盖游戏 `plugin/mods/lizi`。旧 Mod 备份在 `diagnostics/soft-particle-parity-20261114/before-mod/`，不在 Mods 扫描目录中。工程副本保存为 `G:\zmd\机械刀\幻枢归奇.刀_柔光基础重建_20261114.blend`；原工程路径未覆盖。

## 修复预览出生位置采样

发现并复现一项代码缺陷：`eiem_effect_preview.birth_matrices()` 只检查发射器实际父级和骨架的动画，遗漏单独指定的挂点 Empty、目标 Mesh 及其父级。它们未必是特效根的 Blender 父级。来源动画启用时，提前返回也会跳过作者挂点的时间线求值。

修复后枚举 `mount_matrix()` 使用的全部变换依赖；存在作者动画时在各出生时刻求值，再组合来源片段变换，并恢复原帧和子帧。静态挂点仍使用无需跳帧的路径。局部空间不采样历史。此修复不可能自动补出 Blender 中没有导入的游戏角色动作。

`tools/Blender/test_eiem_effect_birth_space_blender.py` 在修复前失败，在修复后通过，覆盖独立挂点、目标 Mesh、其父级、来源片段组合、局部空间及帧恢复。配套部署回归通过 199 项测试（1 项跳过），另运行了真实 Blender 出生位置回归。

## 验证边界

原生逐对象差分、作者资源导出后再导入、四级 LOD 配置检查均通过。20 个固定随机种子下，3 秒时存活 23～32 个粒子，出生位置覆盖三维体积，寿命各异；这只证明数据与预览采样符合设定，不代替游戏截图或实机运动验证。Unity 与离线采样器的随机数算法不同，不承诺每颗粒子的随机位置逐个一致。

证据和可重跑脚本位于 `diagnostics/soft-particle-parity-20261114/`。实机应同时检查武器静止、待机晃动和移动三个条件：静止时出生分布随机分散；运动时旧粒子留在世界，不被武器带走，新粒子从发射器当时的位置出生。不要把正常的世界空间残留当成错误；仍需核对原先波浪状连续带是否还存在。星芒及方块仍按各自原设置工作。

0.50.13 已安装到本机 Blender 5.2 插件目录，64 个包内文件摘要全部一致；回执为 `bin/local-deployments/20261114-155608-798/Blender.json`，配套共享作者 DLL 已同步部署。
