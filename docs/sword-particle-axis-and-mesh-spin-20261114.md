## 轴向修正

静态 Mesh 顶点编辑仅使用 X 镜像；特效 Transform 使用 `(-X,-Z,Y)`。旧挂载直接混用了两个空间，导致 Blender 预览方向与武器运行时方向不一致。

现在静态 Renderer 挂载在原来源 TRS 链之后、作者 Empty/特效根之前增加 X +90° 基变换。非均匀缩放和旋转仍分开保留为原有 TRS 节点，不把它们压成一个有损 TRS。骨骼挂载不额外应用此桥接。仅来源 LOD、全部 LOD 和作者 Empty 挂点使用同一规则；不要再手动给根加一个补偿旋转。

`lod_anchor.2.rotation=0.70710678118654757,0,0,0.70710678118654757` 已出现在两个实际发布的附件声明中。覆盖多个 LOD 使用稳定挂点和同一效果实例，不为四级 LOD 各创建一组粒子。

柔光、星芒和方框继续使用**世界模拟空间**：已出生粒子留在世界，不被武器之后的运动带走；后续新粒子从挂点的新位置出生。新 Mesh 自旋使用**局部模拟空间**，使该单网格跟随武器。

## 方框粒子

发射器：`基础粒子_柔光 / 白色方块_中心扩散`。

材质仍为 `M_白色方块_半透明`。主贴图改为 `G:/zmd/机械刀/particle_square_frame_RA.png`，512×512，柔化方框边缘，外侧为 0，内侧约 48/255，边框约 240/255。RGBA 四通道使用相同覆盖图。

原因是当前材质 `_UseMainTexAsAlpha=1`，会读取 R 参与透明度；原图 RGB 全白、只在 A 中画方框，不能满足当前 Shader 的采样方式。新图同时覆盖 R/A 两种采样。最终透明度还乘材质和粒子的 Alpha，不等于贴图单通道数值。

保留用户当前出生颜色、速度、寿命和发射率；“白色方块”是原有节点名，未据此把用户后来调出的蓝/橙出生颜色强制改回白色。

## 粒子参数如何调整

选中**发射器空物体**，进入属性编辑器的**数据属性 → EFF 特效 · 原生结构 → ParticleSystem**，展开相应模块。不要选预览生成的几何对象修改参数。

| 目的 | 模块与字段 | 说明 |
| --- | --- | --- |
| 整组位置/动画 | `粒子挂点_刀身` | 移动此挂点改变整组位置；可给挂点 K 帧。 |
| 单发射器位置/朝向 | 发射器物体的位置/旋转 | 直接移动、旋转发射器，保持其父子关系。 |
| 出生大小 | 发射器基础 → 出生大小 | 随机范围模式可分别填最小/最大。当前方框可见性复测为 0.06–0.09。 |
| 出生寿命 | 发射器基础 → 出生寿命 (s) | 当前方框为 1.2–1.8 秒。 |
| 初始运动速度 | 发射器基础 → 初速度 (单位/s) | 当前方框为 0.2–0.35；方向来自形状和发射器朝向。 |
| 出生区域/方向范围 | 发射形状与范围 | 类型、半径、圆弧、角度、形状位置/旋转/尺寸；旋转发射器改变整体方向。 |
| 额外运动/减速 | 速度随生命周期 | XYZ、径向速度、速度倍率；这些会与初速度共同作用，不能只看初速度。曲线横轴为寿命比例 0→1。 |
| 连续发射数量 | 发射数量 → 每秒发射数 | 是每秒新生数量；同时检查最大同时存活数是否截断。 |
| 爆发数量/间隔 | 发射数量 → 定时爆发 | 时间、发射数量、重复次数、间隔、概率；可与连续发射叠加。 |
| 整个系统的循环周期 | 发射器基础 → 系统周期 (s)、循环播放 | 与单个粒子寿命不同。 |
| 出生颜色/随机色 | 发射器基础 → 出生颜色 | 颜色、随机双色、渐变随机取色等按实际模式设置。 |
| 淡入淡出 | 颜色与淡入淡出 → Alpha 色带 | 最终透明度还受材质和贴图采样影响。 |
| 自旋速度 | 旋转随生命周期 | 单位 °/s；出生旋转控制初始角度，不控制持续自旋。 |
| 单粒子变大/缩小 | 大小随生命周期 | 倍率曲线乘以出生大小。 |
| 是否跟随武器 | 发射器基础 → 模拟空间 | 散落粒子用世界；常驻旋转 Mesh 用局部。 |

原生模块字段的 XYZ 是游戏坐标；物体 Transform 控件是 Blender 坐标，作者转换负责衔接。调整不明确的方向时优先旋转发射器物体并观察范围预览，不要同时修改根、发射器和形状的补偿旋转。
