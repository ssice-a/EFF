# 2026-10-15：游戏目录与 Mod 导出位置分离

原来的离线导出只根据 `EFF_RELOAD_GAME` 或目标 `plugin/mods` 的父目录取得游戏安装，普通制作/分发文件夹会报错。现在导出窗口、仅 Mesh 导出窗口和插件偏好均提供“游戏目录”和自动识别入口。目录属于本机插件偏好，选择后保存，其他工程共用，不写入作者 `.blend`。

选择优先级为调用方/界面设置、已有环境变量、导出位置所属的游戏目录、自动识别。无效的明确设置直接报告并允许重新选择，不静默改用另一份安装。目录选择支持游戏根、Endfield.exe、Endfield_Data、启动器根或 games 父目录；多份安装需要明确选择。自动识别读取本机注册表安装记录、修复工具本机设置与常见启动器位置，只检查相关目录及 games 的直接子目录，不遍历磁盘资源文件。仅在导出入口或点击自动识别时查询。

原有环境变量与游戏内直接导出方式继续兼容。编译器仍从 Blender 插件自己的 nativepack 加载，按已选择游戏的当前资源与协议编译；生成 Mod 可发布到任意目录。完整编译仍需要本机游戏与当前来源索引，导出路径分离不改变这一资源需求。

新增测试覆盖普通文件夹、独立游戏参数、无效/歧义选择、路径归一、环境变量兼容、导出目录推断、检测线索去重，以及实际编译上下文和公开导出入口传参。导出相关 79 项回归通过（1 项原有跳过），Blender 5.0.1 的三次注册/卸载循环通过。
